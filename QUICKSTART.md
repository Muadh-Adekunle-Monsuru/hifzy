# Hifz Revision Pro - Quick Start Guide

## Installation & Setup (2 minutes)

### 1. Install Dependencies
```bash
npm install
# or yarn install or pnpm install
```

### 2. Start the Development Server
```bash
npm run dev
```

### 3. Open in Browser
Navigate to [http://localhost:3000](http://localhost:3000)

## First Time User - 5 Minute Tour

### Step 1: Explore the Home Page (1 min)
- Click **Home** in navigation to see the dashboard
- View your stats: verses due, mastered, progress, etc.
- Read about the key features

### Step 2: Browse Verses (1 min)
- Click **Verses** to see the verse library
- Browse verses from Surahs Al-Fatiha, Al-Baqarah, Aal-e-Imran
- Search by surah name or translation
- Click any verse to see full details with transliteration

### Step 3: Start Your First Study Session (2 min)
- Click **Study** in the main navigation
- Click "Start Study Session"
- Review each verse that appears:
  - Read the Arabic text
  - Review transliteration
  - Click "Show Translation" if needed
- Rate your recitation (0-5):
  - **5 = Perfect** - Recited flawlessly
  - **4 = Easy** - Correct despite some difficulty
  - **3 = Good** - Correct with some difficulty
  - **2 = Hard** - Correct after hesitation
  - **1 = Difficult** - Correct with serious difficulty
  - **0 = Blackout** - Couldn't remember correctly
- See your session summary when complete

### Step 4: Check Your Dashboard (1 min)
- Click **Dashboard** to see detailed progress
- View charts of your study progress
- See recommendations for improvement
- Track your study streak

## Key Features Explained

### Spaced Repetition System (SM-2)
The app automatically schedules your reviews using a proven algorithm:
- First review: 1 day later
- Second review: 3 days later
- Third review: 7 days later
- Then: Intervals increase based on your performance

**The Better You Perform** → **The Longer Until Next Review**

### Audio Recording (Advanced)

## FAQ

### Q: Do I need internet to use the app?
**A**: No! Hifz Revision Pro is completely offline-first. All your data is stored locally on your device.

### Q: Where is my data stored?
**A**: Your data is stored locally in your browser using WatermelonDB. It never leaves your device.

### Q: How does the SM-2 algorithm work?
**A**: It's a spaced repetition system that:
1. Shows you verses when you're likely to forget them
2. Adjusts timing based on how well you perform
3. Helps maximize long-term memorization

### Q: Can I export my data?
**A**: Yes! Go to Settings → Data & Privacy → Export Data

### Q: Can I use this on my phone?
**A**: Yes! The app is fully responsive and works on any device with a modern browser.

### Q: Why do I need to allow microphone access?
**A**: For the audio recording feature, which lets you practice pronunciation and get feedback.

### Q: What if I want to add more verses?
**A**: For now, we've included 15 verses. In future updates, you'll be able to add custom verses or access the full Quran.

## Troubleshooting

### "Microphone access denied"
1. Check your browser's permission settings
2. Allow microphone access for this website
3. Reload the page and try again

### "Recording not working"
- Make sure you're using HTTPS (or localhost)
- Check if another app is using your microphone
- Try a different browser

### "Data not saving"
- Check if WatermelonDB is available in your browser
- Try clearing your browser cache
- Check browser storage quota

## Glossary

- **Verse (Ayah)**: A single verse from the Quran
- **Surah**: A chapter of the Quran
- **Mastery**: Successfully reviewing a verse 3+ times
- **Interval**: Days until next scheduled review
- **Ease Factor**: How difficult a verse is for you
- **Quality Grade**: Your score for each review (0-5)
